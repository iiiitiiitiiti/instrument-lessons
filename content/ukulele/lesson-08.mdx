## この教材の進行

16小節で1周します。各小節4拍、ダウンストロークだけです。

| 小節 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 1〜4 | C | C | C | C |
| 5〜8 | C | C | G7 | G7 |
| 9〜12 | C | C | F | F |
| 13〜16 | C | G7 | C | C |

歌に合わせたときにコードの変わり目がずれると感じたら、**歌が変わるところで替えてかまいません**。上の表は伴奏の型で、歌のほうが主です。

（歌詞の上にコードを乗せた譜面は、専用の表示ツールと一緒に追加します。それまでは上の表で通してください。）

## 練習の順番

一度に全部やろうとすると崩れます。3段に分けます。

1. **コードだけ**を表の順に押さえる。右手は使わない
2. 表を見ながら**4拍ずつ弾く**。歌わない
3. 歌いながら弾く

3に進むのは、2が止まらずに通ってからです。歌うと手が止まるのは、まだ2が固まっていない合図です。

## つまずくところ

- **8小節目の G7 から9小節目の C** — 3本指から1本指へ戻ります。指を離すのが遅れがちです
- **12小節目の F から13小節目の C** — 共通の指がありません。Lesson 06 でやった動きです
- **14小節目だけ G7 が1小節** — ここだけ短いので、気づかないうちに通り過ぎます。声で「1・2・3・4」を数え続けてください

## 今日の練習

1. 1日目 — 表を見ながら、コードだけを16小節ぶん押さえる。右手なし
2. 2日目 — BPM 50 で16小節を通す。間違えても最後まで行く

**止まったらそこからやり直すのではなく、次の小節に飛び乗ってください**。曲を通す力は、間違えないことではなく、間違えたあとに戻れることです。
