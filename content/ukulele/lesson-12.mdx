ここまでは表でコードの並びを追っていました。今日は**歌詞の上にコードが書かれた譜面**の読み方を覚えます。世の中のコード譜はほとんどこの形なので、これが読めると弾ける曲が一気に増えます。

## 歌詞コード譜の形

歌詞の上にコード名が並んでいて、**コード名が書かれた文字のところでコードを替える**、という決まりだけです。

```
C                  F  C
Oh when the saints go marching in
```

「Oh」で C、「go」の手前で F、「marching」の手前で C に戻る。コード名が乗っている文字を歌う瞬間に、もうそのコードが鳴っている状態にします。

## この教材の書き方

このサイトでは、歌詞の中に角かっこでコードを埋め込む形で書きます。

```
[C]Oh when the saints [F]go marching [C]in
```

上下2段の譜面は、幅の狭い画面では文字とコードの位置がずれます。角かっこの形なら、スマートフォンでも位置関係が崩れません。読むときは**角かっこの直後の文字**でコードを替えます。

この行を実際に組み直すと、こうなります。コード名を押すと、押さえ方と音が出ます。

## 目は1つ先を見る

譜面を読みながら弾けない原因は、ほぼ**目の位置**です。

今鳴らしているコードを見ていると、次のコードに気づくのが遅れます。今のコードは手が覚えているので見る必要がありません。**目は常に1つ先のコードを見ておきます。**

慣れるまでは、次のコードを声に出して予告してください。「つぎ、エフ」と言いながら弾きます。口が言えていれば手も動きます。

## 拍と歌詞は一致しない

表で練習していたときは、1小節に4拍ずつきれいに入っていました。歌詞コード譜ではそうなりません。

- 1つのコードが2小節続くこともある
- 1小節に2つ入ることもある
- 歌い出しが小節の途中から始まることもある（弱起）

**拍を数え続けるのは自分の仕事です**。譜面は「どこで替えるか」しか教えてくれません。ここで Lesson 04 から数え続けてきたことが効きます。
