# Lesson 14 の課題曲を Kuʻu Pua i Paoakalani へ差し替える

- 日付: 2026-09-12
- 依頼: 「Kaimana Hila は別の曲に差し替えてください」（ユーザー）

## 背景

Lesson 14 の課題曲は Kaimana Hila だった。載せているのは1923年版に収められた1916年の原曲で、
今よく歌われている版（Andy Cummings が広めた、著作権表示 1943）とは、旋律と歌詞のどちらも違う。
ユーザーが再生を聴いて「知っているメロディと歌詞と違う」と気づき、差し替えを選んだ。

ユーザーは「自分しか使わないので、知られている版に差し替える案はどうか」とも書いている。
しかしサイトは GitHub Pages で公開されており、1943年の出版物は米国で保護期間中のため載せられない（DDR 004）。
この点は回答済みで、本プランは**権利の切れた別の曲へ差し替える**方針で進める。

## 差し替え先: Kuʻu Pua i Paoakalani

| 候補 | 使うコード | 可否 |
|---|---|---|
| **Kuʻu Pua i Paoakalani（採用）** | C・C7・D7・F・G7 | Lesson 14 までに習うコードだけで弾ける。1917年出版・リリウオカラニ女王（1917年没）で権利も通る |
| Pālolo | A7・C・D7・G7 | A7 は Lesson 15 で習うので、この時点では弾けない |
| Nā Lei o Hawaiʻi | A7・C・D7・G7 | 同じ理由で不可 |
| Hawaiʻi Ponoʻī | — | 1923年版のページにコード記号が無く保留中（DDR 016） |

使うコードの集合が Kaimana Hila と同じ（C・C7・D7・F・G7）なので、カリキュラムのコード導入は変えなくて済む。
C7 を使う課題曲が無くならないのも都合がよい。

**Lesson 14 の到達点「ヴァンプ入りで1曲通る」は保てない**（レビューの指摘。下記）。この曲にヴァンプ
（D7 2拍 → G7 2拍 → C 4拍）の形は無い。コードの並びが D7 → G7 → C になる箇所はある。ただしどれも1小節ずつで、
2拍・2拍・4拍ではない。Kaimana Hila は末尾がちょうどヴァンプの形だったので、到達点が成り立っていた。

代わりに、**到達点を「1小節で2回替わる曲を通す」に変える**。この曲には、1小節の途中でコードの替わる場所が5か所あり、
うち3か所（F→D7 が2回、C→G7 が1回）はちょうど2拍ずつで、Lesson 13 で練習した「2拍で替える」動きがそのまま出てくる。
ヴァンプは自分でイントロとして足せることを本文に書く（お手本の再生には入らない旨も添える）。

曲の性格は静かなので、本文の「明るく賑やかに弾く」という説明も書き換える。

## エッジケース

- `chords` から C7 を外すと、Kaimana Hila の絞り込み（コード数・今の自分が弾ける曲）の結果が変わる。
  4コードの曲として扱われる。Lesson 13 まで終われば弾ける曲に入る
- Kaimana Hila は歌詞コード譜の `[C7]` も外すので、`sheet`・`abc`・`chords` の3か所が食い違わないようにする
  （テストが集合の一致を見ている）
- 古い DDR（004・011・013・014）は当時の課題曲として Kaimana Hila を挙げている。**履歴なので書き換えない**。
  DDR 019 から参照できるようにする

## ステップ

1. 曲データ2つとカリキュラムを直す → `npm test`（課題曲とカリキュラムの一致、コード集合の一致、小節ごとのコード）
2. Lesson 14 の本文を差し替える → `npm test`（レッスンの描画）・`npm run lint`・`npm run build`
3. 仕様と `docs/songs-licensing.md`、DDR 019 を書く → textlint
4. コミット・公開 → 公開版の Lesson 14 と2曲の曲ページを実ブラウザ（幅 320px）で確認


## プランレビュー

- レビュアー: fable-advisor（Claude Fable、作成者の Opus とは別モデル）。プランとコード・曲データ・レッスン本文を読ませた
- 結論の要旨: 差し替え自体は妥当。ただし「ヴァンプが曲の中にある」という前提が不正確で、そのまま本文を書くと Lesson 13 から 14 への接続が嘘になる

### 反映した指摘

1. **最大のリスク: ヴァンプの前提が違う。** 曲データで確かめると、サビは D7 4拍 → G7 4拍 → C（3拍＋C7 1拍）で、
   2拍・2拍・4拍の形はどこにも無い。到達点と Lesson 13 末尾の一文を作り直す（上記）
2. `content/ukulele/lesson-13.mdx` 末尾の「明日の課題曲はこれが頭に付きます」がファイル一覧から漏れていた。足した
3. **Kaimana Hila の C7 撤去は差し替えとは別の話。** 別コミットにし、理由は「課題曲でなくなるから」ではなく
   「旋律の B と C7 の B♭ がぶつかるから」と書く。`arrangement` の「2か所を変えています」も直す
4. 仕様 §4 のコード導入表は、C7 の行に Aloha ʻOe を挙げているが、Aloha ʻOe は C7 を使わない（原典に無い。DDR 015）。
   この機会に Kuʻu Pua i Paoakalani へ直す。§6 の課題曲の表に足す行は、出版1917年（King 編曲版）と作曲1895年を書き分ける
5. DDR 017 の「ユーザーの判断待ち」を DDR 019 から閉じる
6. 曲の紹介文を huapala.org で裏取りする。実際に誤りが見つかった（上記）

### 見送った指摘

- **練習の難度**（16小節・弱起・半拍ずれで Kaimana Hila より読む負荷が高い）— 指摘のとおりだが、
  1日目をダウンストロークだけにする組み立ては元の案でも維持している。曲を変える理由にはしない
