# 013. 歌詞コード譜は「コードと歌詞を同じ塊」にして組み、伴奏再生は持たせない

- 日付: 2026-09-11
- 対象: `src/instruments/ukulele/songSheet.ts`、`src/instruments/ukulele/widgets/SongSheet.tsx`、
  `content/ukulele/lesson-08.mdx`、`lesson-12.mdx`、仕様 §8

## 背景

仕様 §8 の練習ツール7種のうち、SongSheet だけが未実装だった。Lesson 12 は
「歌詞の上にコードが書かれた譜面の読み方」を教える回で、本文に
「この記法を歌詞とコードの2段に組み直して表示するツールは準備中です」という
断り書きが残っていた。教材で説明した記法の実物が出てこない。

DDR 011 で課題曲3曲のレッスンを譜面なしで先に出しており、その後始末もここに含まれる。

Lesson 12 の本文には既に「上下2段の譜面は、幅の狭い画面では文字とコードの位置が
ずれます。角かっこの形なら、スマートフォンでも位置関係が崩れません」と書いてある。
崩れる実装を出すと、教材の説明そのものが嘘になる。

## 決定

### 1. コードは「その歌詞の塊」と同じ箱に入れ、箱ごと折り返す

パーサは1行を `{ chord, text }` の塊の列に分解する。表示側は塊を
`display: inline-flex; flex-direction: column` の箱にして、行の折り返しは
**塊の間だけ**で起こす。コードは自分の歌詞と同じ箱にいるので、幅が変わっても
対応は動かない。320px で対応のずれ 0px・横スクロールなしを実測した。

### 2. 伴奏再生（テンポ可変）は持たせない

この記法はコードが替わる場所しか持たず、各コードの長さを書けない。仕様 §8 の
「全体をテンポ可変で伴奏再生」を外し、仕様側を改訂した。

### 3. コードボタンは高さだけ 44px にする

幅も 44px にすると、`[G7]go ` のような短い塊が押し広げられて歌詞に隙間が入り、
コードと歌詞の対応というこのツールの目的が崩れる。高さは塊の幅に影響しない。

### 4. 譜面を入れるのは聖者の行進だけ

Lesson 08 に、既に公開済みの16小節の表と同じ進行で譜面を入れた。Lesson 11・14
（Aloha ʻOe・Kaimana Hila）は入れず、断り書きの理由を「ツール未実装」から
「小節ごとの割り振りが裏取りできていない」へ書き換えた。

## 比較した代替案

- 却下: **コード行と歌詞行を CSS grid の2行で組む** — 桁は厳密に揃う。しかし grid は
  折り返さないため、320px では横スクロールか縮小になる。Lesson 12 の「狭い画面でも
  崩れません」と両立しない
- 却下: **等幅フォントで空白を詰めて2段に組む（従来のコード譜）** — DDR 011 で既に却下済み。
  折り返した瞬間に対応が崩れる
- 却下: **記法に小節線 `|` を足す** — 小節線があれば「1つのコードが2小節続く」ことが
  目で見え、伴奏再生の長さも決まる。だが Lesson 12 が教えている規則は
  「角かっこの直後の文字でコードを替える」の1つだけで、本文は公開済み。
  表示ツールのために教える規則を増やすのは順序が逆
- 却下: **使用コードの図を譜面の上に常時並べ、押したコードを強調する** — 図の出し入れで
  レイアウトが動かない。しかしスマートフォンで歌詞を読んでいるとき、強調される図は
  画面の外にある。図は歌詞より下に置き、そこが伸びても読んでいる行が動かない形にした
- 却下: **未定義のコード名を黙って素通りさせる（押せない文字として出す）** — レッスンが
  真っ白にならない。だが綴りの間違いに気づけない。既存の ChordDiagram・ChordPlayer と
  同じく描画時に投げ、全レッスンを描画するテストで拾う形に揃えた
- 却下: **3曲すべてに譜面を入れる** — 形は揃う。だが Aloha ʻOe と Kaimana Hila は
  小節ごとの割り振りを裏取りできていない。裏取りのない譜面を置くと、読み手はそれを
  正解として練習してしまう（DDR 011 と同じ理由）
- 採用: **塊単位の折り返し＋伴奏再生なし＋聖者の行進だけ譜面を入れる**

## 影響範囲

- 仕様 §8 の練習ツールは7種すべて実装済みになった
- DDR 011 の「本文中の断りはそのとき削る」は、聖者の行進については完了。
  残る2曲はプランC（楽譜ライブラリ）で出典を付けてから
- 伴奏再生が必要になったら、記法へ小節線を足すところから始まる。パーサは行単位の
  純関数なので、拡張はそこに閉じる

## 検証

- 167 tests（パーサ17件・コンポーネント8件を新規追加）/ lint / build 通過。
  追加したテストは実装をわざと壊して落ちることを確認した
- 実ブラウザ（dist を preview、Playwright）で実測した。320px で横スクロールなし。
  コードと歌詞の左端のずれ 0px。全15レッスンで溢れなし。390px で各行が1段に収まる。
  コード名を押すと4音鳴り、図の読み上げ文も正しい

判断が間違いだったとわかるのは、塊単位の折り返しが読みにくいという声が出たとき。
その場合は塊の幅を揃える（桁を作る）方向へ寄せるが、折り返しは捨てない。
