# 003. 音は合成し、音源ファイルを持たない

- 日付: 2026-09-10
- 対象: `src/core/audio/`

## 背景

教材として、コードの響き・音程・リズムを耳で確認できる必要がある。テキストと図だけでは、リズムと音程のどちらも伝わらない。手本の音をどう用意するかを決める必要があった。

## 決定

Karplus-Strong 法でブラウザ内合成する。音源ファイルは同梱しない。

波形の生成は Web Audio へ依存しない純関数として切り出し、テスト可能にする。遅延線の丸めで生じる音高のずれは、再生時に `playbackRate` で打ち消す。

## 比較した代替案

- 却下: **フリーライセンスの実音サンプルを同梱** — 音はリアルになる。ただしライセンスの裏取りが要るうえ、数十MBの管理も発生する。オフライン動作にも不利
- 却下: **オシレータの単純な波形（正弦波・矩形波）** — 実装は最も軽い。ただし弦楽器に聞こえず、音程確認以上の役に立たない
- 却下: **補正なしの Karplus-Strong** — レビューで指摘を受け、A4 で +12.5 セントずれると判明した。チューニングの基準音としては使えない
- 却下: **分数遅延の補間による正確な合成** — 音程は正確になる。ただしコードが複雑で、`playbackRate` による補正で同じ結果が得られる
- 採用: **Karplus-Strong + 再生速度による音高補正**

## 影響範囲

- PWA のオフライン動作（[005](005_split-plan-into-three.md) 参照のプランA Task 11）。音源の取得が不要なため、機内モードでも教材が成立する
- チューナー・メトロノーム・ストロークパターン再生・伴奏再生のすべてが、この1つの音源実装を共有する
- リポジトリの容量

## 検証

波形の基本周期を自動相関で測るテストを置き、申告した実効周波数と一致することを検査する。

**判断が間違いだったとわかる条件:** 合成音が耳障りで練習の妨げになる、あるいは弦の響きとして認識できないとき。その場合は音源層だけを差し替える（インターフェースは `playNotes()` に閉じている）。
