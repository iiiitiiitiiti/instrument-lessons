# 004. 掲載曲は日本と米国の両方で保護期間が満了したものに限る

- 日付: 2026-09-10
- 対象: 楽譜ライブラリの収録判定、`docs/songs-licensing.md`

## 背景

弾き語りの練習には曲が要る。市販曲の歌詞・コード譜をサイトへ転載すると著作権の問題が生じるため、掲載できる曲の条件を最初に決める必要があった。

サイトは GitHub Pages で公開する。GitHub Pages は米国のホストであり、日本法だけの判定では足りない。

## 決定

次の両方を満たす曲だけを掲載する。

- **日本** — 作詞者・作曲者の**両方**が1967年12月31日までに死亡している（または伝承曲）
- **米国** — 初出版が1929年より前である

曲データに検証記録（作者・没年・初出版年・確認日・出典URL）を必須フィールドとして持たせ、条件を満たさない曲があればテストでビルドを落とす。

有名曲は曲名を挙げて外部コード譜サイトへリンクするに留め、歌詞・コード譜は転載しない。

## 比較した代替案

- 却下: **日本法だけで判定** — 「赤とんぼ」は日本では PD だが、1927年発表のため米国では保護が継続している。米国ホストで公開する以上、この判定では漏れる
- 却下: **作曲者の没年だけで判定** — 「夕焼小焼」は作曲の草川信（1948年没）だけを見ると PD に見える。実際は作詞の中村雨紅が1972年没で、2042年まで保護される
- 却下: **人が目視で確認する運用** — 曲を足すたびに判断が要り、抜けたときに気づけない
- 却下: **曲を扱わず練習フレーズのみ** — 安全だが、達成感がなく「弾き語り3曲」という目標が成立しない
- 採用: **二重基準 + ビルド時の機械検査**

## 影響範囲

- 楽譜ライブラリの収録候補（ハワイアン曲を中心に、Live Ukulele の PD 候補リストから個別に裏取りする）
- 課題曲3曲の選定（聖者の行進 / Aloha ʻOe / Kaimana Hila）
- 曲を追加するときの手順（出典URLなしでは登録できない）

## 検証

日本の保護期間については、文化庁の Q&A で「施行日時点で消滅していた著作権は復活しない」ことと、1967年12月31日までに死亡した著作者の作品が満了済みである点を確認した。

除外の判断が働くことは、「夕焼小焼」と「椰子の実」の作者の没年を実際に調べて確かめた。どちらも保護期間中で、除外が必要と確定した。

**判断が間違いだったとわかる条件:** 権利者から連絡が来たとき。その場合は該当曲を外し、判定条件の穴を記録へ残す。
