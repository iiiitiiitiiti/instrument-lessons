# 020. 歌詞の意味は原詞から訳し、各行の下に出す

- 日付: 2026-09-12
- 対象: `src/instruments/ukulele/songs/types.ts`・6曲のデータ、`widgets/SongSheet.tsx`・`SongSheet.css`、
  `pages/SongPage.tsx`、`mdxComponents.tsx`、`tests/ukulele/songs.test.ts`・`SongSheet.test.tsx`、
  `docs/songs-licensing.md`
- プラン: `docs/superpowers/plans/2026-09-12-lyric-meanings.md`（レビュー記録あり）

## 背景

ユーザーから「英語わからんよ」と言われた。歌詞コード譜はハワイ語と英語のまま出しており、
意味が分からないまま練習している状態だった。ハワイ語の5曲だけでなく、聖者の行進も英語詞のままだった。

## 決定

### 1. 訳は原詞から作る

ハワイ語の語義は wehe.hilo.hawaii.edu（Pukui-Elbert 1986 ほか）で引き、引けた語釈を曲データのコメントに残す。
**1923年版に印刷されている英語詞は、意味の照合にだけ使う。** 歌うための意訳で、原詞と行が対応しない
（Kaimana Hila では英語詞に合わせて音符が足されている）。英語詞の全文はリポジトリに書かず、ページ番号だけ残す。
huapala.org の英訳は意味の確認だけに使い、表現は写さない（DDR 014 と同じ理由）。

### 2. 辞書で裏が取れない語は、取れないと明記する

この辞書は同綴りの別語が先に並ぶため、歌詞の文脈の義に届かない語がある（`pua`・`uka`・`mākou`・`onaona` など）。
地名と雨の名も引けない。**機械的に語釈を集める方針はやめ、確かに引けた語だけを根拠として残した。**
残りは原譜の英語詞と huapala.org の解説で意味を確かめ、引けなかったことを曲ごとのコメントに書いた。

### 3. 表示は歌詞の各行のすぐ下

行の中の塊組み（DDR 013）は `inline-flex` の話なので、行の後ろに要素を置いても折り返しは変わらない。
歌詞を二重に出さないので、幅 320px でも縦に短い。意味の要素には `.songsheet__text` を使わない
（既存のテストが歌詞の文字を数えているため）。

### 4. データは行の文字列と対で持つ

`meaning?: { line, meaning }[]` とし、`line` は歌詞コード譜の歌詞行そのもの。添字だけの対応にすると、
歌詞へ行を足したときに行数が一致したままずれる。テストで `line` と歌詞の一致も検査する。

## 比較した代替案

- 却下: **1923年版の英語詞を訳の元にする** — 手早い。しかし歌うための意訳で行が対応せず、
  「どの行が何を歌っているか分かる」という成功条件を満たせない（プランレビューの指摘）
- 却下: **huapala.org の英訳を訳す** — 意味が明快。しかし訳者の権利がある
- 却下: **譜面の下に行ごとの意味をまとめて並べる** — 譜面と意味を分けて読める。しかし歌詞を二重に出すので
  画面が長く、行の対応を目で追う手間が残る
- 却下: **`<details>` で畳む** — 譜面が短く保てる。しかし今回の依頼は「意味が分からない」なので、既定で見せたい
- 却下: **別ページにまとめる** — 譜面が汚れない。しかし練習の途中でページを行き来する手間が生まれる
- 却下: **歌える日本語（歌詞として歌える訳）にする** — 歌いながら意味が入る。しかし語の対応が崩れ、
  意味を確かめる用途に向かない
- 採用: **原詞から訳し、行の文字列と対で持ち、各行の下に出す**

## 影響範囲

- 曲を足すときは `sheet` と一緒に `meaning` も書く。無いとテストが落ちる
- 歌詞を直したら `meaning[].line` も直す。テストが食い違いを落とす
- **訳は専門家の校閲を受けていない。** 誤りが残りうることを `docs/songs-licensing.md` に書いた

## 検証

- 行数の一致・`line` と歌詞の一致・意味が空でないこと・各行の直後に出ること・渡さなければ出ないことをテストで確認した
- 公開版の曲ページを実ブラウザ（幅 320px）で確認した。横スクロールは出ない

判断が間違いだったとわかるのは、ユーザーが訳を読んで意味が取れないと感じたとき、
またはハワイ語に詳しい人から誤訳を指摘されたとき。その場合は該当の行を原詞と辞書で読み直す。
